# AI 자동 대국 실험

## 2026-10-14 · 현재 규칙 그대로, 실험당 200판

원본 데이터: `docs/experiments/2026-10-14/exp{1..4}.jsonl`
재현: `godot --headless --path client -s res://tools/simulate.gd -- --experiment=N --games=200 --seed=200N`

### AI
- 공통 안전 규칙: 이길 수 있으면 이긴다 / 다음 착수에 지는 위협(4목, 줄로 만든 5목)은 막는다 /
  상대에게 즉시 승리를 넘겨주는 줄은 긋지 않는다.
- 성향은 평가 가중치만 다르다. 공격형: 내 연결 1.0, 상대 견제 0.4 / 방어형: 0.4, 1.0
- 1수 앞만 보는 AI다. 사람의 깊은 수읽기와는 다를 수 있다.

흑 승률의 95% 신뢰구간은 약 ±7%p (200판 기준). 성향 조합별(약 50판)은 ±14%p.

성향 맞대결 (실험 3 / 4, 색 무관): 공격형 승 41.0% / 45.0%, 방어형 승 54.3% / 45.9%

### 관찰
1. **800판 중 줄로 5목을 만들거나 끊은 경우가 한 번도 없다.** 줄 긋기는 전체 행동의 26~32%를 차지하지만
   모두 공간 확보나 "패스"로 쓰였고, 승리는 전부 착수로 완성한 5목이다.
2. **둘 다 공격적이면 빠르지만 흑이 압도적이다** (흑 82%, 중앙값 41수).
3. **4×4를 돌로 먼저 채우는 오프닝은 흑 우위를 크게 줄인다** (흑 52% vs 백 43%).
4. **무승부는 줄 긋기로 시간을 보내는 대국에서만 나왔다.** 실험 4의 무승부 10판은 모두 4×178 판으로,
   높이 4에서 양쪽이 세로줄만 계속 그어 450수에 도달했다. 실험 3의 무승부는 80×142 같은 거대한 판이다.
